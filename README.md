# Салым — ИИ-сотрудник для малого и среднего бизнеса

Малый бизнес не может держать администратора, бухгалтера, SMM-щика и HR одновременно.
**Салым** — один ИИ-агент с общей памятью о бизнесе, который закрывает эту рутину.
Модули — это не отдельные сервисы, а **навыки одного агента**, связанные между собой:

> Заявка из Instagram → агент ответил клиенту → создал сделку → после оплаты выставил счёт →
> доход попал в бухгалтерию → аналитика заметила слабый день → маркетинг предложил акцию →
> статистика ответов попала в мониторинг сотрудников.

Демо-проект для хакатона. Работает локально, **без интернета и без ключа ИИ**.

---

## Быстрый старт

Нужен Node.js 18.18+ (проверено на Node 24 LTS).

```bash
npm install && npm run dev
```

Откройте http://localhost:3000. По умолчанию загружен салон красоты «Aru Beauty», г. Тараз.

Сборка для продакшена: `npm run build && npm start`.

## Как включить реальный ИИ

По умолчанию работает **демо-режим**: агент отвечает заранее подготовленными текстами,
которые считаются из данных бизнеса и «печатаются» по словам. Чтобы ответы генерировала
настоящая модель:

1. Скопируйте `.env.example` в `.env.local`.
2. Укажите один из ключей:
   - `ANTHROPIC_API_KEY=...` — Claude (по умолчанию модель `claude-opus-5-5`, можно сменить через `ANTHROPIC_MODEL`);
   - или `OPENAI_API_KEY=...` (модель `gpt-4o-mini`, меняется через `OPENAI_MODEL`).
3. Перезапустите `npm run dev`.

В шапке индикатор сменится с «демо-режим» на «ИИ: Claude». Ключ используется только на сервере
(API-роут `app/api/ai/route.ts`), в браузер не попадает. Если API недоступен, агент молча
переключится на демо-ответ — демо не сломается посреди показа.

## Сценарий демо (3–4 минуты)

Перед показом нажмите **Ctrl + Shift + R** (или тройной клик по логотипу «Салым», или
«Мозг агента → Автономность → Сбросить демо») — данные вернутся в исходное состояние.

1. **Главная.** KPI (заявки сегодня, выручка, конверсия, время ответа агента, сэкономленные часы),
   лента «Что агент сделал сегодня», блок «Агент заметил»: «Выручка по вторникам ниже на N%».
2. **Заявки и чаты → «Симулировать входящее»** (стрелка справа — выбрать Instagram).
   Приходит сообщение от нового клиента, агент печатает ответ в реальном времени, клиент
   соглашается, агент записывает его и создаёт сделку — она подсвечивается во вкладке «Воронка».
   Можно переключить диалог в «Вручную» и показать перехват менеджером.
3. **Воронка.** Перетащите сделку в «Оплачено» (или «⋯ → Переместить в…»). Появляется тост
   «Агент выставил счёт № СЧ-…» → «Открыть» — вы в **Бухгалтерии**, счёт уже в документах
   (кнопка «Скачать PDF» печатает документ), доход — в операциях с пометкой «новое».
4. **Агент-бухгалтер** (панель справа): «Что съело прибыль в этом месяце?» — ответ с цифрами,
   причиной и сравнительным графиком.
5. **Маркетинг → Умные акции → «Запустить»** на слабый день: генератор сам пишет рекламный текст
   с хэштегами, справа — мокап поста Instagram. «Опубликовать» → тост «Опубликовано в Instagram».
   Во вкладке «Контент-план» — «Заполнить план».
6. Быстро покажите расширения:
   - **Сотрудники** — таблица, рейтинг, инсайт «Айгерим отвечает в 3 раза медленнее вечером»;
   - **HR** — скоринг резюме, «ИИ-собеседование» → «Начать» → отчёт;
   - **Звонки → «Симулировать звонок»** — анимированный голос и расшифровка по ходу разговора;
   - **Мозг агента** — услуги, правила, каналы, уровень автономности.

Переключатель бизнеса в шапке (салон / кафе / магазин / автосервис) подгружает другие демо-данные.

**Командная палитра — Ctrl + K** (или поле «Поиск» в шапке): переход в любой раздел, поиск клиента,
действия (симуляция заявки или звонка, смена темы, сброс демо, смена бизнеса), все шаги сценария демо
и «Спросить агента: …» — вопрос сразу уходит агенту на главной. Удобно вести показ без мыши.

## Телефон и ПК

Интерфейс адаптирован под ноутбук и монитор (1366–1920 px), планшет и телефон (от 360 px):

- на телефоне — нижняя панель навигации, как в приложении, остальные навыки в меню «Ещё»;
- чаты работают как мессенджер: список → переписка с кнопкой «назад», карточка клиента — в выезжающей панели;
- воронка листается по этапам; карточку можно перенести долгим нажатием или через «⋯ → Переместить в…»;
- агент-бухгалтер на узких экранах — отдельная вкладка, контент-план показывается лентой по дням;
- таблицы скрывают второстепенные колонки, тосты появляются сверху, поля не вызывают масштабирование на iOS.

**Открыть демо с телефона из любой сети** (мобильный интернет и т. п.) — через Cloudflare Tunnel,
без регистрации:

```bash
npm run build && npm start
```

Во втором окне терминала:

```bash
cloudflared tunnel --url http://localhost:3000
```

В консоли появится ссылка `https://….trycloudflare.com` — её и открывайте на телефоне. Ссылка
работает, пока запущены оба окна, и меняется при каждом новом запуске туннеля. Если команда
`cloudflared` не найдена, используйте полный путь `"C:\Program Files (x86)\cloudflared\cloudflared.exe"`.
Сайт по ссылке доступен любому, у кого она есть, — после показа просто закройте туннель.

Открыть демо с телефона в той же Wi-Fi-сети: запустите `npm run dev` и откройте адрес из строки
`Network:` в консоли (например, `http://192.168.1.10:3000`). Данные демо хранятся в браузере каждого
устройства отдельно.

## Что внутри

| Модуль | Возможности |
| --- | --- |
| Главная | KPI, лента действий агента, инсайты с кнопками действий, «Спроси агента» |
| Заявки и чаты | Единый инбокс (Instagram, WhatsApp, Telegram, сайт, 2ГИС), авто/ручной режим, карточка клиента, симулятор, канбан-воронка, мониторинг отзывов с готовыми ответами |
| Бухгалтерия | Доходы/расходы, графики, структура расходов, операции, счета/акты/накладные с печатью, налоговый календарь ИП (форма 910), агент-бухгалтер |
| Маркетинг | Умные акции из данных, генератор контента с превью, контент-план, рекламные кампании |
| Сотрудники | Показатели, активность, рейтинг, инсайты |
| HR | Генерация вакансий, скоринг кандидатов, ИИ-собеседование с отчётом |
| Звонки | Журнал с расшифровками, «живой звонок», настройки голосового бота |
| Мозг агента | База знаний, правила, каналы, автономность |

Налоговые расчёты — демонстрационная оценка (базовая ставка 4% по упрощённой декларации, НК РК 2026);
перед реальной сдачей сверяйтесь с кабинетом налогоплательщика.

## Стек и структура

Next.js 15 (App Router) · TypeScript · Tailwind CSS + компоненты в стиле shadcn/ui (Radix) ·
lucide-react · Recharts · Zustand с сохранением в localStorage · sonner (тосты) · next-themes.

```
app/                 страницы модулей и API-роуты ИИ (/api/ai, /api/ai/status)
components/ui/       базовые UI-компоненты
components/<модуль>/ компоненты модулей
components/layout/   сайдбар, шапка, оболочка
lib/data/            профили бизнесов и детерминированный генератор демо-данных
lib/analytics.ts     все расчёты (KPI, инсайты, слабый день, «что съело прибыль»)
lib/agent/           промпты, демо-ответы, контент, налоги, HR
lib/ai.ts            слой ИИ: реальная модель или демо-печать
lib/simulation.ts    симулятор входящих заявок
store/               Zustand: данные бизнеса и временное состояние
```

Все данные генерируются детерминированно от текущей даты (60 дней истории) и согласованы между
модулями: выручка в KPI = сумма операций в бухгалтерии, выручка сотрудника = его операции,
инсайты считаются из тех же транзакций.
